# Fund Estimation Task Plan (PlanA + PlanB)

目标：短时涨跌最接近最终净值；30s 内更新，准确 + 性能并重。

## 0. 当前状态
- PlanB 已上：天天基金估值 JSONP + 东方财富重仓 HTML + 腾讯行情（qt.gtimg.cn）并发计算。
- 前端已改为批量轮询 `/api/funds/estimate/rt`。

## 1. PlanB 强化（实时估值兜底）
- 目标：在持仓覆盖率不足或行情缺失时，给出明确 `is_realtime=false`。
- 任务：
  - 接口层缓存（10-30s TTL），避免频繁抓取。
  - 覆盖率与置信度字段标准化：`coverage`, `is_realtime`, `source`。
  - 失败路径：返回明确 error 字段，前端提示“实时不可用”。

## 2. 数据抓取与本地缓存（训练与在线共用）
- 目录结构（本地 `data/`）：
  - `data/rt_quotes/YYYYMMDD/` 腾讯股票行情快照（每 10-30s）。
  - `data/fundgz/YYYYMMDD/` 天天基金 JSONP 原始数据。
  - `data/holdings/` 基金重仓快照（按基金、按季度）。
  - `data/features/YYYYMMDD/` 特征缓存（覆盖率、持仓加权收益等）。
  - `data/models/` 训练好的模型与元数据。
- 任务：
  - 后端新增采集任务（定时抓取 + 写入本地）。
  - 统一时间戳、交易时段标签、异常数据剔除。

## 3. 特征工程（PlanA 核心）
- 持仓加权收益：`sum(weight_i * ret_i)`。
- 覆盖率特征：`coverage`、未覆盖的权重分桶。
- 行业/指数补全：行业指数、风格指数、基准指数收益。
- 时间特征：交易时段、开盘/午盘/尾盘分段。
- 历史误差修正：过去 N 日估值偏差的均值与波动。

## 4. 模型训练（PlanA）
- 模型方向：GBDT / CatBoost / XGBoost（快、稳定、可解释）。
- 训练目标：
  - 预测 `est_return`（盘中 -> 当日最终净值涨跌）。
  - 输出 `confidence`（基于覆盖率 + 模型不确定性）。
- 训练流程：
  - 滚动窗口回测（按交易日切分）。
  - 不同时间段单独评估（9:30-10:30, 10:30-11:30, 13:00-14:00, 14:00-15:00）。
  - 选择误差最小的模型与特征组合。

## 5. 在线推理与融合
- 逻辑：
  - PlanA 模型可用 -> 输出模型估值。
  - PlanA 不可用 -> PlanB 估值（持仓 + 腾讯行情）。
  - 覆盖率不足 -> 回退 fundgz，并标记 `is_realtime=false`。
- API 输出字段：
  - `est_nav`, `est_return`, `coverage`, `confidence`, `source`, `is_realtime`。

## 6. 性能与缓存
- 缓存层：内存 + 本地文件（或 Redis）。
- 并发策略：批量请求 + 限制并发（8~16）。
- 轮询：前端 10-30s；优先命中缓存。

## 7. 评估与监控
- 误差监控：MAE/MAPE，分时段误差。
- 异常告警：估值偏离过大/数据源异常。
- 训练可重复：保存训练数据切片与模型版本。

## 8. 里程碑
1. PlanB 缓存与稳定性加强
2. 数据抓取与本地缓存落地
3. 特征工程基线 + 回测
4. 模型训练与线上推理集成
5. 误差监控与自动更新
