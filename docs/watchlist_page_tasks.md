# 自选页面（原搜索页面）任务清单

目标：将现有“搜索页面”更名为“自选页面”，在同一页面内完成自选组件与搜索组件的整合，并实现持仓相关功能与展示。

## 待办事项（设计稿级别）
1. 页面标题与导航文案改为“自选”。
2. 页面布局分区：搜索区、自选列表区、持仓列表区（同页可见）。
3. 分类筛选控件（全部/持有/已清仓/偏股/偏债/指数/全球）。
4. 自选列表表头与字段展示（基金名称/基金代号、净值、添加后收益、各时间区间收益）。
5. 持仓列表表头与字段展示（名称/持有金额、日收益、持有收益、累计收益、今日收益更新提示）。
6. “/” 同单元格双行/双列样式设计（标题与内容对齐）。
7. 空态与加载态：无数据提示、加载中的骨架或占位。
8. 字段格式与对齐：金额、收益率、小数位、正负号及颜色标识。
9. 交互入口：新增持仓、编辑持仓、删除持仓、清仓标记。
10. 持仓输入表单：当日持有金额录入、校验、保存提示。
11. 今日收益更新状态的视觉提示（角标/点位/文字）。
12. 分页或滚动方案（数据量较大时）。

## 页面结构与模块
1. 页面更名
   - 将“搜索页面”命名为“自选页面”。
2. 页面模块（同一页面内）
   - 自选组件（含自选列表）
   - 搜索组件
   - 持仓列表组件

## 自选列表（字段与展示）
1. 必填字段
   - 基金名称 / 基金代号（同一单元格展示）
   - 净值（当天）
   - 添加后收益
   - 近一周 / 近一月 / 近三月 / 近六月
   - 今年来 / 近一年 / 近二年 / 近三年 / 近五年 / 成立来
2. “/” 表示同一单元格内需要显示两个内容。

## 持仓列表（字段与展示）
1. 必填字段
   - 名称 / 持有金额（同一单元格展示）
   - 日收益
   - 持有收益
   - 累计收益
   - 今日收益是否更新的提示
2. “/” 表示同一单元格内需要显示两个内容。

## 分类筛选（自选视图）
分类项固定包含：
- 全部
- 持有
- 已清仓
- 偏股
- 偏债
- 指数
- 全球

## 持仓 CRUD 需求
1. 持仓新增/编辑/删除/读取（CRUD）
2. 当用户在“当天”输入持有金额后：
   - 从当天开始计算收益
   - 自动加减仓（根据后续输入的持有金额变化自动调整）

## 交互与状态
1. 持仓列表需展示“今日收益是否更新”的提示状态。
2. 自选与持仓数据需在同一页面内可直观看到与对比。
