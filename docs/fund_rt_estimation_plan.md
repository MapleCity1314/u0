# Fund RT Estimation Plan (Short-Term Accuracy)

目标：短时涨跌最接近最终净值（盘中估值误差最小），可接受 10–30 秒级更新。

## 决策摘要
- 数据源：由实现方选取，允许新增指数/行业/期货等数据源。
- 训练存储：本地 `data/`（轻量、低复杂度）。
- 在线更新：前端轮询后端缓存（无需 WebSocket/SSE）。
- 模型：偏复杂（优先轻量 GBDT / CatBoost / XGBoost 等），保持低延迟推理。

## 评价指标（核心）
- 目标：短时涨跌最接近最终净值。
- 建议指标：
  - MAE/MAPE（估值涨跌 vs 最终净值涨跌）
  - 分段误差（9:30-10:30、10:30-11:30、13:00-14:00、14:00-15:00）
  - 覆盖率与置信度校准（coverage / confidence）
- 训练/回测：滚动窗口回测，按交易日切分。

## 数据源规划（可扩展）
- 基金估值：天天基金 JSONP（fundgz）
- 持仓：东方财富重仓（HTML）
- 行情：腾讯财经（qt.gtimg.cn）
- 补全：行业指数、风格指数、指数期货（可选）

## 数据层设计
- 抓取 -> 入库（本地 data/）-> 特征缓存 -> 在线推理
- 本地存储：
  - 建议结构：
    - `data/rt_quotes/` 实时行情（按日期分片）
    - `data/holdings/` 持仓快照
    - `data/fundgz/` 估值 JSONP 原始数据
    - `data/features/` 特征缓存
    - `data/models/` 模型与评估产物

## 特征工程（核心）
- 持仓加权实时涨跌（股票/ETF）
- 行业/风格补全因子（覆盖不足时补权）
- 基准指数回归（基金与指数相关性）
- 期货/ETF 对冲因子（如可用）
- 历史误差修正因子（过去 N 天的偏差）
- 交易时段因子（开盘/午盘/尾盘）

## 模型训练
- 模型类型：轻量 GBDT（如 XGBoost / LightGBM / CatBoost）
- 输出：
  - `est_return`（短时涨跌估值）
  - `confidence`（置信度/可靠性）
  - `coverage`（实际持仓覆盖率）
- 训练策略：滚动窗口回测 + 最优超参选择

## 在线估值（PlanA + PlanB）
- PlanA（模型估值）：
  - 使用缓存的实时特征 + 模型推理
  - 低延迟，主要输出
- PlanB（数据直推）：
  - 持仓 + 腾讯行情直接估值
  - 覆盖率不足时 fallback 到 fundgz

## API 设计（建议）
- `POST /api/funds/estimate/rt`
  - 输入：`{ codes: string[] }`
  - 输出：每个基金 `est_return / est_nav / confidence / coverage / source / is_realtime`
- 轮询周期：10–30s

## 缓存与性能
- 缓存层：内存 + 本地文件（按分钟更新）
- 并发抓取：限制并发数（如 8~16）
- 推理：批量推理，避免逐个请求

## 里程碑
1. 数据抓取与本地缓存
2. 特征构建与回测基线
3. 模型训练 + 评估
4. 在线估值服务 + 前端轮询

## 备注
- 后续可加“模型热更新”与“异步训练”。
