# u0

**u0** 是一个 **AI 驱动的持续金融分析与量化研究平台**，
专注于解决 **“传统金融数据滞后、分析割裂、决策不可持续”** 的问题。

当前 MVP 聚焦于一个非常具体、但真实存在的痛点：

> **在官方基金净值发布之前，提供可解释、可跟踪的盘中基金估值能力。**

---

## 为什么要做 u0？

在现有金融工具中：

* 基金净值 **T+1 才公布**
* 盘中只能看指数、股票，**不知道基金真实在涨还是在跌**
* 基金分析严重依赖：

  * 滞后的持仓披露
  * 静态标签（“偏股 / 偏债 / 成长”）

**u0 的目标是：**

> 让金融分析从「事后解释」变成「持续推断」。

---

## 核心能力（当前 & 规划）

### ✅ 已实现 / MVP 阶段

* 📈 **基金盘中实时估值（模型驱动）**

  * 基于历史净值 + 市场因子回归
  * 分钟级更新
  * 给出估值区间与置信度
* 🔍 **基金风格暴露识别**

  * 自动识别大盘 / 中盘 / 成长 / 小盘等因子权重
* 🧪 **实验优先（Labs）**

  * 所有新模型、新想法先在 `labs/` 中验证

### 🚧 规划中

* 🧠 模型自学习（长期残差修正）
* 📊 基金横向对比 & 真实强弱排名
* 🌍 QDII / 海外资产支持
* 🧩 多资产统一估值框架（基金 / 组合 / 策略）

## 项目结构说明

```text
u0/
├─ apps/        # 可运行的应用（Web / Admin）
├─ services/    # 后端服务（FastAPI / 推理服务）
├─ core/        # 核心算法与计算逻辑（无框架依赖）
├─ models/      # 可复用的模型定义
├─ data/        # 数据接入、缓存与中间结果
├─ labs/        # 实验 / demo / 快速验证
├─ infra/       # 部署、CI、Docker、IaC
└─ docs/        # 架构与产品文档
```

**设计原则：**

* `labs` → 探索与试错
* `services` → 稳定能力 & API
* `apps` → 面向用户的产品形态

实验成功的能力，会从 `labs` **毕业**进入 `services` 或 `core`。

## 快速开始（MVP Demo）

### 1️⃣ 安装依赖

```bash
pip install -r requirements.txt
# 或
pip install akshare pandas numpy scikit-learn
```

### 2️⃣ 运行基金实时估值 Demo

```bash
python labs/fund_nav_rt_022485/main.py
```

你将看到类似输出：

```json
{
  "fund": "022485",
  "estimated_nav": 1.41,
  "estimated_return": "+0.83%",
  "confidence": "medium",
  "dominant_factor": "HS300"
}
```

> 注意：盘中估值效果请在 **A 股交易时段**观察。
